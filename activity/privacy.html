Privacy Policy

Last updated: July 2026

Degens Against Decency is a parody party game spectator app for Discord. We collect only what is needed to run the game:

  • Discord user ID and username when you authorize via Discord Activity
  • Channel ID to show live game state for that channel
  • Basic server logs (errors, uptime) on our hosting provider

We do not sell your data. Game card submissions are handled in Discord; the spectator view does not display hidden player hands.

Contact: open an issue on the project GitHub repository.
